# العجاج - الإيجارات

تطبيق Android مستقل لإدارة المستأجرين والإيجارات والتحصيلات.

## المواصفات
- Android 9 (API 28) وما فوق.
- واجهة عربية RTL.
- تخزين محلي يعمل دون إنترنت.
- مستأجرون، استحقاقات شهرية، دفعات جزئية، إيصالات مرقمة، كشف حساب.
- نسخ احتياطي واستعادة محلية بصيغة JSON.
- تجهيز بنية قابلة لإضافة النسخ الاحتياطي إلى Google Drive بعد ربط حساب Google.

## قاعدة احتساب الإيجار المعتمدة
- أول استحقاق: نوفمبر 2026.
- ينشأ الاستحقاق في آخر يوم من الشهر لكل مستأجر نشط.
- لا يُكرر الاستحقاق للشهر نفسه.
- تغيير قيمة الإيجار يطبق على الاستحقاقات المستقبلية فقط، وتظل القيود القديمة محفوظة.

## البناء
افتح المشروع في Android Studio أو شغّل:
`./gradlew assembleDebug`

> النسخة الحالية هي أساس أولي قابل للتطوير؛ يلزم اختبار APK على جهاز فعلي قبل الاعتماد النهائي.
